# MAP-A decision gate

Do not decide a product change from historical anecdotes.

After all valid replay rows are populated, classify each task shape as one of:

- Map consumption reduces reading/context;
- Map improves discovery but costs more context;
- exact graph consumption beats ranked expansion;
- Map adds cost without useful consequence;
- missing observation truth causes unsafe interpretation;
- no Map product change justified.

MAP-B may contain product code only when at least one measured row supports a concrete correction and the correction removes more duplicated decision/context cost than it adds.
